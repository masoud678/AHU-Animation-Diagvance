# AHU Interactive Animation

Interactive Air Handling Unit (AHU) animation built for Diagvance.

The project demonstrates how outdoor air and return air move through an AHU, including:

- Mixing dampers
- Filter
- Heating coil
- Cooling coil
- Supply fan
- BAS controller
- Outdoor / Return / Mixed / Supply air temperatures
- Cooling and heating modes
- Adjustable outdoor air percentage
- Animated airflow and temperature-based color changes
